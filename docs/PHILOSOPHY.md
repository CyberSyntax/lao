# Philosophy

We pursue extreme rigor.

1. **Micro**: Guardrails shape small units. Functions get shorter. Nesting and
   complexity drop. Duplication vanishes.
2. **Macro**: A tiny, explicit architectural intent (dependencies, side‑effect
   boundaries, concurrency and determinism rules) is enforced continuously by
   automated fitness functions.

We never trade determinism, reproducibility, or clarity for convenience.
